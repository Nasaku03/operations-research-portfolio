# Chromatic Sum by Modular Decomposition

## Overview

This project contains C++ research code related to the **Coloring Sum Problem**, also known as the **Minimum Sum Coloring Problem (MSCP)**, and the use of **modular decomposition** in graph optimization.

The problem assigns positive integer colors to graph vertices so that adjacent vertices receive different colors, while minimizing the sum of the assigned colors.

## Research Focus

This project collects implementations and experiments related to solving the Coloring Sum Problem using modular-decomposition-based techniques. Consult the source files and accompanying research documentation for the exact algorithms and variants implemented here.

## Requirements

- Microsoft Visual Studio 2022 or newer
- Desktop development with C++ workload
- CPLEX is used to solve integer linear problems that are built in Prime nodes in the research tree.

## Build and Run

1. Open the relevant `.sln` or `.vcxproj` file in Visual Studio.
2. Check the project's configuration and required dependencies.
3. Select `Debug` configuration.
4. Build the project.
5. Run it using the input format expected by the implementation. There is the DIMACS format or the adjacent matrix format.
