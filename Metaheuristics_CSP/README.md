# Metaheuristics for the Coloring Sum Problem (CSP)

## Overview

This directory contains C++ research code implementing metaheuristic approaches for the **Coloring Sum Problem (CSP)**, also referred to as the **Minimum Sum Coloring Problem (MSCP)**.

The problem assigns positive integer colors to graph vertices so that adjacent vertices receive different colors, while minimizing the sum of the assigned colors.

## Research Focus

This project focuses on metaheuristic approaches to the Coloring Sum Problem. Several metaheuristics are implemented such as **The sonar algorithm**, **Tabu search**, **Multi-neighberhood rules**, **General exchange rules**, ...
