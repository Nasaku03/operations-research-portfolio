# Operations Research and Optimization Algorithms

This repository contains C++ implementations developed through my research in Operations Research, with a focus on exact algorithms for multiobjective combinatorial optimization and the Minimum Sum Coloring Problem (MSCP).

## Projects

### 1. Multiobjective Optimization
C++ implementations of exact methods for solving multiobjective optimization problems and analyzing efficient solutions.

### 2. Minimum Sum Coloring Problem (MSCP)
Several implementations and algorithmic versions for solving the Minimum Sum Coloring Problem, a graph coloring problem that aims to minimize the sum of the colors assigned to the vertices.
