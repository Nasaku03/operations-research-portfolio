# Operations Research and Optimization Algorithms

C++ research implementations in combinatorial optimization, multiobjective optimization, graph theory, and metaheuristics.

## Projects

- [Chromatic Sum by Modular Decomposition](ChromaticSumByModularDecomposition/README.md) — implementations related to the Minimum Sum Coloring Problem (MSCP) and modular decomposition.
- [Linear Integer Optimization over MOQIP](LinearIntegerOptimizationOverMOQIPEpsilon/README.md) — research code related to multiobjective linear and non-linear optimization problems and the linear optimization over the efficient set of a multiobjective quadratic integer programming problem.
- [Metaheuristics for CSP](Metaheuristics_CSP/README.md) — metaheuristic implementations associated with a Coloring Sum Problem.

## Development Environment

- **Language:** C++
- **IDE:** Microsoft Visual Studio 2022 or newer
- **Optimization software:** IBM ILOG CPLEX and/or GAMS, where required by an individual project
- **Platform:** Windows (project-specific requirements may vary)

See each project's README for its scope, dependencies, and available build instructions. Exact compilation steps and solver versions should be confirmed against the corresponding Visual Studio project files.

## About

This portfolio collects research-oriented implementations developed in the field of Operations Research. My research interests include exact algorithms, combinatorial optimization, multiobjective optimization, and graph theory.
